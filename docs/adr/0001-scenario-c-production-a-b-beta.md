# v1.0: Scenario C is Production, Scenarios A and B are Beta

Scenario C is the default path and the cheapest, so v1.0 commits to it at the Production bar (one behavioural eval per skill plus one real end-to-end pilot). Scenarios A and B stay in the bundle with their known Blockers fixed, but are labelled Beta because none of their skills downstream of the Design export has established compatibility with real output. Dropping them would waste working skills; calling them Production would promise something nobody has verified.
