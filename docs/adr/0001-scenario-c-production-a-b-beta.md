# v1.0: Scenario C is Production, Scenarios A and B are Beta

Scenario C is the default path, the cheapest, and the only one with a repo available for a real end-to-end pilot, so v1.0 commits to it at the Production bar (one behavioural eval per skill plus one real pilot). Scenarios A and B stay in the bundle with their known Blockers fixed, but are labelled Beta because none of their skills downstream of the Design export has ever run on real output. Dropping them would waste working skills; calling them Production would promise something nobody has verified.
