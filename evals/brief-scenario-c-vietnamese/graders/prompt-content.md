The part of this file between the COPY markers is a Design prompt written in English (UI copy quoted from the project may stay as it is; no Vietnamese sentences). It asks for the look only (layout, spacing, colours, fonts, component states), prefers plain HTML with one CSS file and CSS variables, and asks for no routing, state or real backend. It does not forbid React or other frameworks and does not say framework code will be discarded. It asks for one page or route per Screen and names the Today, All reminders and Settings screens, and it quotes real copy from the project such as "Done", "Notification time" or "Save".
